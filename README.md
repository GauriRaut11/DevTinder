DevTinder 💻
A full-stack web application that helps developers discover, connect and collaborate with other developers.

Features
User signup and login with JWT authentication.
Developer profile creation and management.
Swipe-based developer discovery.
Send, accept and manage connection requests.

Tech Stack
Frontend: React.js, JavaScript, Tailwind CSS, DaisyUI, Redux Toolkit.
Backend: Node.js, Express.js, MongoDB, Mongoose.
Tools: Git, GitHub, Postman.
